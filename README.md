# Library Management System

A responsive, browser-based library manager for keeping a small book collection organized. It runs without a build step or server.

## Features

- Add, edit, and remove books
- Track availability with check-out and return actions
- Search titles and authors, or filter by availability
- View live totals for all, available, and checked-out books
- Save the collection in the current browser with `localStorage`

## Run it

Open `index.html` in a modern browser. The initial collection is sample data; changes are saved in that browser and do not sync between devices.

## Files

- `index.html` — application structure
- `styles.css` — responsive layout and styling
- `app.js` — collection behavior and browser storage
